# 30 关核心验收

最终串行命令 `scripts/test_campaign.sh`、`scripts/test_core.sh --focused` 均退出 0。30/30 实际核心回放通关，8043 次断言；focused 核心回归 661 次断言通过。当前 authored seed 的 30 关均已观察到三星路径，最少 6 发、最多 45 发；这些是有限搜索得到的可执行路径，没有声称最短解或平均玩家难度。

时间按生产场景计算：弹丸完整折线路径长度 / 1250，结算呈现 0.38 秒，每回合至少 2 秒，压行到期按当前阶段延迟至呈现完成，终态立即停止计时。每关最多 180 步，没有无界搜索。JSON 中保存发射器、瞄准坐标、队列、Hold、技能、飞行耗时及回合时间预算。

50 个 authored waves 全部具有到顶行的支撑路径，30 开局颜色布局 hash 独立，开局几何有 28 种；20 个第二波均改变几何。Fall 保留独立吊柱、翼形支撑、分叉桥三种结构。Collect 的 authored 目标色总供给为 43/31/44/41/49/49，均覆盖 20/25/30/35/40/45 的目标。收集统计包含匹配时刚发射的目标色糖，因此单凭开局色供给不足不能证明关卡无法通关。

长路径定向收敛：L11/L15/L25 保留几何和波数，加宽同色支撑段；L8/L13 支撑色延伸至可触及的一行。L8/L23 掉落目标收敛至 40，L28 收敛至 36，避免 authored 内容耗尽后依赖随机压行补货。Collect 增加第二波；L27 的第二波仅镜像一次，并补足目标色支撑组。生存三星使用发射效率及得分门槛，其 parShots 按 2 秒节奏设为 31/35/38/42/45/49；各关依然必须真实消除并使用技能救场。

有限末波清场不生成新关卡波，失败优先于同帧达标，冻结只暂停压行而不暂停生存时间，胜利后拒绝继续操作，1/2/3 星、进度不降级、Top 50 排序/持久化/重复终态幂等、legacy format1 及错误快照边界均通过。新增 operations 属性列表验证，防止坏快照在终态诊断落盘时抛异常。两条 CLI 脚本仅在测试链接 TestDefaults.m，在 main 前将 standardUserDefaults 指向 UUID suite，成功和断言失败 exit 均清理，不覆盖玩家 bestScore、lastRun、进度或榜单。

本报告验证核心真实引擎，不代表模拟器触控或真机体验已完整验收；UI 运行证据由独立 QA 提供。尚需用户实际试玩判断章节难度和三星门槛，当前没有缺少三星 witness 的关卡。未执行 xcodebuild、模拟器或提交。
