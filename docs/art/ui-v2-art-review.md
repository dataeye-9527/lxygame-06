# UI v2 美术验收记录

日期：2026-09-30。范围：独立运行位图与真实 UI 截图的视觉验收；不替代玩法、导航或设置功能验证。

## 资源

- 复用已批准的四色圆形压印软糖、奶油粉色炮台、万能星与淡紫边缘装饰背景。无玻璃、机械、人物、地图、货币等风格或功能扩展。
- 新增 `Resources/Images/menu_hero.png`，640×480 真实 RGBA，源图和内置生成提示词留存。
- 8 项运行图片的尺寸与 SHA-256 均匹配 `asset-manifest.json`。7 项独立素材 alpha 为 0..255，环境背景全 255。棋子和炮台主体 alpha 接近全不透明，弱 alpha 主要在边缘。
- 主菜单插画黑底放大可见极弱彩色边缘碎点；alpha≥16 没有孤立像素，实际淡紫背景截图没有可感知的噪点。不通过人工抹边更改生成主体。

## 首轮开始页

证据：`build/qa/ui-v2/home.png`，真实 iPhone 模拟器截图。

- 四色炮台插画与程序标题、最佳分、菜单卡组成完整界面，视觉重量平衡。
- 插画显示 520×390 逻辑点，主体清晰且无人物或烘焙文字；透明边缘在实际背景不可感知。
- 蓝色 Play 为主操作，粉色 Settings、黄色 How to Play 为次操作；正文与按钮对比清楚。
- 胶囊高光、柔影、奶油卡的内边与炮台材质相互呼应；背景装饰集中在外围，不压菜单内容。
- 首轮问题：横屏两侧 SKView 黑边；已在单背景修复后复验中确认修复。

旧运行 `before.png` 只用于前后对照，不作为新界面完成证据。

## 单背景修复后复验

归档证据：`docs/qa/ui-v2/home-final.png`、`game-final.png`、`settings-final.png`、`help-final.png`、`paused-final.png`、`result-final.png`，均为现有 iPhone 17 模拟器的真实运行截图。生成样图与资源原图未用作运行完成证据。

- 开始页通过：宽屏两侧应用黑边和中央背景矩形接缝已消失；单一全屏淡紫背景连续，边缘装饰没有覆盖主体。四色炮台插画、标题、最佳分与 New Game / Resume / Settings / How to Play 四按钮层次清楚，文字可读，无重叠。
- 游戏页通过：截图为普通触控游玩后的 SCORE 395 局面；四色圆形压印软糖在 18/17 密棋盘中仍可辨认，深紫棋盘、奶油面板、粉色计时器和危险线保留批准样图的结构与配色。
- 实际炮台与 Wild 星形通过：运行图能确认使用独立位图；左炮装黄色棋子的视觉中心位于炮口内，未见需要调整的可感知偏移。三炮台材质一致，激活台有蓝色底圈；Wild 星与普通白色圆环棋子明显区分。
- 技能控件通过：SWEEP 同时以黄色描边、满进度条和 READY 显示可用；其他技能显示颜色填充和独立数值。左技能区、顶部 SCORE / NEW ROW / 暂停、右侧 NEXT / HOLD、底部炮台均无重叠。
- 设置页通过：三行标签与 On / Off 清楚，开启蓝色、关闭淡紫色，并有明确文字；Back 位置清楚。帮助页通过：操作说明与四列技能图标和短文案可读、间距完整；WILD 的最终 `auto-match a color` 说明已在最新 Debug 应用补取运行图，文字完整无截断。
- 暂停页通过：奶油弹窗、标题与 Resume / Retry / Settings / Home 操作清楚，外侧遮罩与棋盘内遮罩连续覆盖全屏，没有两侧未变暗区域或接缝。
- 结束页通过：普通真实局压行触发 Game Over 后的标题、得分与 Retry / Home 操作清楚；全屏遮罩连续。该图不依赖 DEBUG 失败 fixture。
- 设备左侧的黑色 Dynamic Island 属于系统硬件区域；页面内容已在安全区内避开，不计为应用黑边。

六页的截图呈现与全屏背景 / 遮罩修复已通过 PM 目视验收。此美术复验只确认上述截图的呈现；导航、设置持久化、技能玩法证据见 README 第 13 节与 `docs/qa/ui-v2/README.md`。真机手感与其他屏幕比例尚未验收。
